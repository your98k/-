组卷台安卓应用隐私说明

更新日期：2026 年 11 月 9 日

组卷台提供本地练习生成、方程专项、可选的个人 AI 接口出题、错题收藏和文件导出。应用无需注册，不内置项目作者或公共付费 AI 账号。

本机数据

接口地址、模型名称、当前试卷和错题收藏保存在设备的应用私有存储中。API Key 或代理访问口令仅保存在当前应用进程的内存中，应用退出或进程结束后需要重新填写；不会写入偏好设置、试卷、导出文件或日志。应用禁用系统数据备份。

AI 接口和第三方服务

AI 为可选功能。只有在点击 AI 生成或测试连接时，应用才会向你自行配置的 HTTPS 接口发送请求。生成请求包含学科、学段、年级、学期、知识点、难度、题量、题型和少量近期题干（用于避免重复）；API Key 作为认证请求头发送到该接口。项目作者不接收这些请求或密钥。若你填写代理地址，请同时了解代理运营方和上游模型服务商的数据处理规则与费用。

你需要自行取得并使用有权调用的 API 服务，并遵守服务商的使用规则。AI 生成的题目、答案和解析需要人工核验。

权限和导出

联网权限用于你主动发起的 AI 请求。导出 PDF 或 Word 时，通过安卓文件选择器将内容写入你选择的位置，不申请访问全部文件的权限。只有主动点击复制或分享时，相关试卷文本才会进入剪贴板或你选择的分享应用。

数据删除

在“设置 → 清除本机全部数据”中可删除本机接口设置、试卷和错题，并清除当前内存中的密钥。卸载应用也会删除应用私有数据。此前自行导出或分享的文件需要在相应位置单独删除；已经发送给 API 服务商的请求按其政策处理。

广告和统计

此版本不包含广告、行为统计或用户画像 SDK，不读取联系人、位置、相册、麦克风或设备广告标识。

联系和更新

如有隐私问题，可通过项目问题反馈页面联系维护者，请勿在公开反馈中附上 API Key、访问口令或其他个人信息。本说明会随功能变化更新。
