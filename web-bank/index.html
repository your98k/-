个人 API 设置

仅支持 OpenAI 兼容的 Chat Completions 接口。API Key 只在本页内存中保留，刷新后需重新填写；不会上传到 GitHub，也不会写入本地存储。

保存时只记住地址和模型，不发送请求。点击 AI 生成才会调用你填写的接口并按服务商计费，Key 也只发给该地址；请使用可信接口及低额度专用 Key。

接口必须支持浏览器跨域（CORS）与 HTTPS。网络或 CORS 错误不能靠关闭浏览器安全限制解决；不要使用公共代理转发密钥。
